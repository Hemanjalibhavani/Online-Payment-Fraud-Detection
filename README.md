# Online Payment Fraud Detection Using Machine Learning

## 📌 Project Overview

This project focuses on detecting fraudulent online payment transactions using Machine Learning techniques. The model analyzes transaction-related features and classifies transactions as **fraudulent or legitimate**.

## 🎯 Objective

The main objective is to build a machine learning-based fraud detection system that can identify suspicious online payment transactions and help reduce financial losses caused by fraudulent activities.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* XGBoost
* Matplotlib
* Seaborn
* Google Colab
* Jupyter Notebook

## 🤖 Machine Learning Algorithms

The project explores multiple classification algorithms, including:

* Logistic Regression
* Random Forest
* XGBoost

## 🔄 Project Workflow

1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Feature Selection
5. Train-Test Split
6. Model Training
7. Model Evaluation
8. Fraud Prediction

## 📊 Evaluation Metrics

The models are evaluated using metrics such as:

* Accuracy
* Precision
* Recall
* F1-Score
* ROC-AUC

## ▶️ How to Run

### Using Google Colab

Open the `.ipynb` file in Google Colab and run the notebook cells sequentially.

### Using Jupyter Notebook

Install the required libraries:

```bash
pip install -r requirements.txt
```

Then open:

```text
Online_payment_fraud_detection.ipynb
```

and run the cells.
